# Dota Draft AI v8 — 4 известных героя противника

Теперь интерфейс работает со сценарием:

```text
Наша команда:
4 известных героя
+ ищем пятого

Противник:
4 известных героя
+ 1 неизвестный герой
```

## Почему нельзя было просто убрать пятый слот

Старая сеть обучалась только на полных 5v5 драфтах.

Если просто передать `0` вместо пятого противника, сеть увидит вход,
которого почти никогда не было при обучении.

Поэтому v8 специально обучается на маскированных драфтах.

В 60% train-примеров случайно скрывается один герой:

```text
hero = 0
position = 0
pick_order = 0
```

Таким образом сеть учится анализировать неполный драфт.

## Порядок запуска

Старый detailed dataset подходит.

Если `data/detailed_matches.csv` уже существует,
повторно скачивать матчи не обязательно.

Обучить v8:

```bash
python -m src.train_nn_v8
```

Запустить новый интерфейс:

```bash
python -m streamlit run src/recommend_app_v8.py
```

## Новые метрики

Во время обучения выводятся:

```text
train_loss
full_logloss
partial_logloss
partial_auc
partial_acc
```

Для текущей задачи важнее всего:

```text
partial_logloss
partial_auc
```

потому что именно они измеряют качество модели,
когда один герой противника неизвестен.

## Интерфейс

Вводится:

- 4 наших героя;
- их позиции;
- порядок их пиков;
- 4 героя противника;
- их позиции;
- порядок пиков противника;
- позиция нашего пятого героя;
- средний MMR;
- bracket.

Если у четырёх противников указаны четыре разные позиции,
позиция неизвестного пятого определяется автоматически.

## Запуск

```bash
python -m src.train_nn_v8
python -m streamlit run src/recommend_app_v8.py
```
